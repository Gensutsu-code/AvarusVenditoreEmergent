**Key Technical Concepts**:
- **Hybrid Storage Routing:** Files > 95MB are kept local to bypass Cloudinary's 100MB free-tier limit. Smaller files go to Cloudinary.
- **Chunked File Uploads:** Custom implementation bypassing Kubernetes Nginx proxy limits (set to 4MB chunks) with an auto-retry mechanism on HTTP 502 errors.
- **HTTP 206 Range Streaming:** Used in FastAPI to stream massive local  files to the frontend React video player.
- **Token-in-Query Authentication:** Local streaming uses  in the  attribute of video/img tags since native HTML elements cannot pass Bearer headers.

# Магазин грузовых автозапчастей - PRD

## Проблема
Создание интернет-магазина грузовых автозапчастей с каталогом, корзиной, оформлением заказов и личным кабинетом.

## Архитектура
- **Frontend**: React + Tailwind CSS + Shadcn UI
- **Backend**: FastAPI + MongoDB
- **Auth**: JWT tokens (bcrypt для паролей)
- **Media Storage**: Cloudinary

## Ключевые API Endpoints

### Скидки и статусы (новые)
- GET /api/discount-settings — публичные настройки скидок с порогами
- GET /api/admin/discount-settings — настройки скидок (admin)
- PUT /api/admin/discount-settings — обновить настройки скидок (admin)
- POST /api/request-status-upgrade — запрос на повышение статуса
- POST /api/request-individual-discount — запрос на индивидуальную скидку
- GET /api/my-requests — мои текущие запросы
- GET /api/admin/notifications — счётчики уведомлений
- GET /api/admin/status-requests — список запросов на статус
- PUT /api/admin/status-requests/{id}?action=approve|reject
- GET /api/admin/discount-requests — список запросов на скидку
- PUT /api/admin/discount-requests/{id}?action=approve|reject

# Магазин грузовых автозапчастей — PRD

## Проблема
Интернет-магазин грузовых автозапчастей с каталогом, корзиной, оформлением заказов, системой скидок, бонусной программой и личным кабинетом.

## Архитектура
- **Frontend**: React + Tailwind CSS + Shadcn UI + ethers.js
- **Backend**: FastAPI + MongoDB
- **Auth**: JWT tokens
- **Media**: Cloudinary
- **Documents**: python-docx + ReportLab
- **Платежи**: ЮKassa (карты), Крипто (MetaMask + ручная проверка)

## Реализованный функционал

### v1.0–v4.0 — MVP + Расширение
- Каталог, корзина, заказы, авторизация
- Админ-панель, промо-баннер, бонусы, чат, Telegram
- Аналитика, импорт/экспорт

### v4.1 — Система скидок и статусов (11.02.2026)
- Статусы: Розница, Опт, Партнёр
- Скидки по статусам + индивидуальные
- Динамические цены в каталоге
- Запросы на повышение статуса и скидку
- Админ-уведомления в шапке

### v4.2 — Документы, платежи, уведомления (11.02.2026)
- **Документы**: Товарная накладная + чек (WORD/PDF)
- **Наличие**: Списание при заказе, восстановление при отмене
- **Бонусы**: Исправлено начисление
- **Скидки**: Прибавление (не замена)
- **Призы**: Управление в админке
- **Оплата**: 3 способа (наличные/карта/крипто)
- **Скидки по оплате**: Настройка в админке
- **ЮKassa**: Интеграция для карт РФ (требует API ключи)
- **Крипто**: MetaMask + ручной TX hash на ETH/BSC/Base/TRC
- **Кошельки**: Настройка адресов в админке
- **Уведомления**: Клиентские + админские
- **Новости**: CRUD в админке + страница /news
